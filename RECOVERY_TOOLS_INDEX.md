## 🛠️ Recovery Tools

### 1. **quick-recover.ts** ⭐ MAIN TOOL
**Purpose:** Recover private keys from addresses

**Usage:**
```bash
npx ts-node quick-recover.ts
npx ts-node quick-recover.ts --seed "custom-seed" --max-id 50000
```

**What it does:**
- Reads `addresses_with_balances.json`
- Generates addresses for userIds 1-10000
- Matches them with your addresses
- Recovers private keys
- Saves to `recovered_addresses.json`

**Output:**
```
✓ Matched: 95
✗ Not found: 5
Total BNB: 0.0855
```

**Time:** ~2-10 minutes

---

### 2. **transfer-recovered-bnb.ts** ⭐ TRANSFER TOOL
**Purpose:** Transfer BNB from recovered addresses to your wallet

**Usage:**
```bash
npx ts-node transfer-recovered-bnb.ts
```

**What it does:**
- Loads `recovered_addresses.json`
- Asks for target wallet address
- Transfers BNB to your wallet
- Saves transfer results
- Handles gas fees automatically

**Interactive prompts:**
```
Enter target wallet address: 0x...
Leave BNB for gas fees (default 0.0001): 
Proceed with transfer? (yes/no): yes
```

**Output:**
```
✓ Successful: 94
✗ Failed: 1
Total BNB Transferred: 0.0847
```

**Time:** ~5-30 minutes

---

### 3. **verify-recovery.ts**
**Purpose:** Verify recovered addresses and private keys

**Usage:**
```bash
npx ts-node verify-recovery.ts
npx ts-node verify-recovery.ts --check-balances
```

**What it does:**
- Verifies private key format
- Verifies address format
- Checks private key → address derivation
- Checks userId → private key regeneration
- (Optional) Checks blockchain balances

**Output:**
```
Private Key Verification:
  Total Checked: 95
  ✓ Valid: 95
  ✗ Invalid: 0
```

**Time:** ~1-5 minutes

---

### 4. **recover-addresses.ts**
**Purpose:** Advanced recovery with detailed logging

**Usage:**
```bash
npx ts-node recover-addresses.ts
```

**Features:**
- Detailed logging for each address
- Batch operations
- More control over process
- Useful for debugging

**Time:** ~30-60 minutes (slower but more detailed)

## 📊 Recommended Workflow

### Quick Recovery (Recommended)
```bash
# Step 1: Recover addresses (2-10 min)
npx ts-node quick-recover.ts

# Step 2: Verify recovery (1 min)
npx ts-node verify-recovery.ts

# Step 3: Transfer BNB (5-30 min)
npx ts-node transfer-recovered-bnb.ts

# Step 4: Verify transfer (1 min)
cat transfer_results.json

# Step 5: Clean up (IMPORTANT!)
rm recovered_addresses.json
```

```bash
# Step 1: Recover with logging (30-60 min)
npx ts-node recover-addresses.ts

# Step 2: Verify with blockchain check (5-10 min)
npx ts-node verify-recovery.ts --check-balances

rm recovered_addresses.json
```

## 🔧 Command Reference

### Recovery Commands

```bash
# Basic recovery (default seed, search 1-10000)
npx ts-node quick-recover.ts

# Custom seed
npx ts-node quick-recover.ts --seed "my-seed"

# Larger search range
npx ts-node quick-recover.ts --max-id 50000

# Custom file
npx ts-node quick-recover.ts --file path/to/addresses.json

# Combined
npx ts-node quick-recover.ts --seed "my-seed" --max-id 50000 --file addresses.json
```

### Verification Commands

# Verify and check blockchain balances
npx ts-node verify-recovery.ts --check-balances

## ⚙️ Configuration

### Wallet Seed
The addresses were generated using:
```
seed = `${userId}-${WALLET_SEED}`
```

**Default:** `'default-seed'`

If you used a custom seed:
```bash
npx ts-node quick-recover.ts --seed "your-seed"
```

### Search Range
Default searches userIds 1-10000. For more addresses:
```bash
npx ts-node quick-recover.ts --max-id 50000
```

### Gas Fees
- Default reserve: 0.0001 BNB per address
- Adjustable in transfer script
- Typical cost: 0.00001-0.00005 BNB per transfer

## 🐛 Troubleshooting

### "No matching userId found"
```bash
# Try custom seed
npx ts-node quick-recover.ts --seed "your-seed"

# Try larger search range
npx ts-node quick-recover.ts --max-id 50000
```

### "Insufficient balance"
- Address might have been emptied
- Check `addresses_with_balances.json` for actual balance

### "Transaction failed"
- Verify target address is correct
- Check network connectivity
- Ensure sufficient gas fees

### "File not found"
- Ensure `addresses_with_balances.json` exists
- Run from correct directory
- Use `--file` parameter if needed
