# Address Recovery Guide

## Overview
This guide explains how to recover the BNB from the addresses generated by `BSCService.generateUserWallet()`.

## How Addresses Were Generated

The addresses in `addresses_with_balances.json` were generated using a deterministic seed:

```typescript
generateUserWallet(userId: number): { address: string; privateKey: string } {
  const seed = `${userId}-${process.env.WALLET_SEED || 'default-seed'}`;
  const hash = crypto.createHash('sha256').update(seed).digest('hex');
  const account = this.web3.eth.accounts.privateKeyToAccount('0x' + hash);
  return { address: account.address, privateKey: account.privateKey };
}
```

**Key Points:**
- Each address is derived from a `userId` and a `WALLET_SEED` environment variable
- The seed is hashed using SHA256
- The hash becomes the private key
- The private key can be used to recover the address and transfer its funds

## Recovery Process

### Step 1: Understand Your Wallet Seed
The recovery script needs to know the `WALLET_SEED` used when generating these addresses.

**Default value:** `'default-seed'`

If you used a custom seed, you'll need to provide it.

### Step 2: Run the Recovery Script

The recovery script (`recover-addresses.ts`) will:

1. **Scan** all addresses in `addresses_with_balances.json`
2. **Find** the userId for each address by testing different userIds
3. **Recover** the private key for each address
4. **Save** the recovered data to `recovered_addresses.json`
5. **Optionally** transfer BNB to a target address

### Step 3: Use the Recovered Addresses

Once recovered, you can:
- **View** all private keys in `recovered_addresses.json`
- **Transfer** BNB to a central wallet
- **Access** the funds from any wallet application

## Quick Start

### Option A: Just Recover (No Transfer)

```bash
# Install dependencies
npm install

# Run recovery
npx ts-node recover-addresses.ts
```

This will create `recovered_addresses.json` with all recovered addresses and private keys.

### Option B: Recover and Transfer

Edit `recover-addresses.ts` and uncomment the transfer section:

```typescript
// Step 3: Optional - Transfer BNB to a target address
console.log('\nSTEP 3: Transferring BNB...');
const targetAddress = '0xYourTargetAddressHere'; // Replace with your target address
const transferResults = await recovery.batchTransferBNB(targetAddress);
```

Then run:
```bash
npx ts-node recover-addresses.ts
```

## Important Notes

### ⚠️ Security
- **NEVER** share the `recovered_addresses.json` file
- **NEVER** commit it to version control
- The file contains all private keys
- Delete it after transferring funds

### 🔍 Search Depth
By default, the script searches up to userId 10000. If you generated more addresses, increase this:

```typescript
await recovery.recoverAddressesFromFile(addressesFilePath, 50000); // Search up to 50000
```

### ⏱️ Performance
- Searching for each address takes time (depends on userId range)
- The script adds delays between transactions to avoid nonce issues
- For 100 addresses with 10000 userId search: ~30-60 minutes

### 💰 Gas Fees
- Each transfer costs gas (BNB)
- The script reserves 0.0001 BNB for gas fees by default
- Adjust with: `recovery.batchTransferBNB(targetAddress, '0.0002')`

## Troubleshooting

### "No matching userId found"
- The address might not have been generated with the current seed
- Try a different `WALLET_SEED` value
- Increase the search range

### "Insufficient balance"
- The address might have been emptied already
- Check the BNB balance in `addresses_with_balances.json`

### "Transaction failed"
- Ensure you have enough BNB in the source wallet
- Check network connectivity
- Verify the target address is correct

## Manual Recovery (If Script Fails)

If the script doesn't work, you can manually recover addresses:

```typescript
import crypto from 'crypto';
import Web3 from 'web3';

const web3 = new Web3();
const userId = 1;
const walletSeed = 'default-seed'; // Your seed

const seed = `${userId}-${walletSeed}`;
const hash = crypto.createHash('sha256').update(seed).digest('hex');
const privateKey = '0x' + hash;
const account = web3.eth.accounts.privateKeyToAccount(privateKey);

console.log('Address:', account.address);
console.log('Private Key:', account.privateKey);
```
