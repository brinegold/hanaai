# 🔑 Address Recovery Toolkit

Recover and transfer BNB from addresses generated by `BSCService.generateUserWallet()`.

## 📋 Quick Start

### 1. Recover Addresses
```bash
npx ts-node quick-recover.ts
```

This will:
- Read `addresses_with_balances.json`
- Find the userId for each address
- Recover private keys
- Save to `recovered_addresses.json`

**Output:**
```
✓ Matched: 95
✗ Not found: 5
Total BNB: 0.0855
```

### 2. Transfer BNB (Optional)
```bash
npx ts-node transfer-recovered-bnb.ts
```

This will:
- Load recovered addresses
- Ask for target wallet address
- Transfer BNB to your wallet
- Save transfer results

## 🔧 Advanced Options

### Custom Wallet Seed
If you used a custom seed during address generation:

```bash
npx ts-node quick-recover.ts --seed "my-custom-seed"
```

### Larger Search Range
If you generated more than 10,000 addresses:

```bash
npx ts-node quick-recover.ts --max-id 50000
```

### Custom File Path
```bash
npx ts-node quick-recover.ts --file path/to/addresses.json
```

## 📁 Files Generated

## ⚠️ Security Notes

- **NEVER** commit `recovered_addresses.json` to git
- **NEVER** share this file with anyone
- **DELETE** after transferring funds
- Keep your `.env` file with `WALLET_SEED` safe

## 🚀 How It Works

### Address Generation (Original)
```typescript
const seed = `${userId}-${WALLET_SEED}`;
const hash = SHA256(seed);
const privateKey = '0x' + hash;
const address = deriveAddress(privateKey);
```

### Address Recovery (This Tool)
```
1. Load all addresses from JSON
2. Generate addresses for userIds 1 to N
3. Match generated addresses with loaded addresses
4. Extract private keys for matches
5. Save recovered data
```

## 🐛 Troubleshooting

### "No matching userId found"
- Check your `WALLET_SEED` value
- Try increasing `--max-id`
- Verify addresses are from this system

### "Insufficient balance"
- Address might have been emptied
- Check `addresses_with_balances.json` for actual balance

### "Transaction failed"
- Ensure target address is correct
- Check network connectivity
- Verify sufficient gas fees
